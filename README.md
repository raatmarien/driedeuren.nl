# Driedeuren.nl

Een website waar je het driedeuren probleem kan spelen of 100 keer kan simuleren.

De code is open source onder de [GNU aGPL v3+](https://www.gnu.org/licenses/agpl-3.0.txt), dus doe ermee wat je wil, maar deel daarna wel weer de broncode.

## Aan de slag

Installeer eerst NPM, [zie hier](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm)

Installeer dan de dependencies:

```
npm install
```

Om het locaal te runnen:

```
npm run dev
```

Om de html/css/js te generen om waar je maar wil online te zetten:

```
npm run build
```
